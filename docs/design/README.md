# PC 布局参考与迭代记录

## 当前方案：原生分栏与左侧 Tab

后续用户授权开启 `frameset` 并将桌面 Tab 放在左侧。Windows 首页现采用自适应竖向导航＋既有列表；按首页实际页面宽度分为：<640px 的 60px 图标栏、640～959px 的 160px 图标文字栏、≥960px 的 200px 图标文字导航＋下方纵向热门板块。板块使用现有真实数据，不在其他侧栏重复显示。详情/发帖由各自原生页面承载，不在另一栏复制导航或完整三栏。

手机底部 Tab 保留。macOS 桌面首页导航使用同一三档，宽屏仍保留自定义三栏和右侧热门讨论，但不据此声称支持微信原生分栏。导航内容在高度不足时滚动，发帖入口留在底部。具体策略和验证缺口见根目录 README 的“桌面微信布局”。

下面三栏参考图及 HTML 为先前阶段的设计记录，不代表当前 Windows 单个分栏应继续显示三列。

以下文件为更早提出的居中单栏设计方案，留作评审记录：
